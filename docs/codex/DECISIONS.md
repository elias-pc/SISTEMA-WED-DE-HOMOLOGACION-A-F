# Decisiones

## Parámetros de homologación por empresa

Los filtros, tipos documentales, vigencias, dictámenes y módulos se almacenan como configuración JSON por empresa. Esto evita valores fijos y permite que cada cliente tenga su propia plantilla sin duplicar el flujo global.

La fecha de vencimiento de un entregable se deriva en frontend para informar al usuario y se recalcula en backend para preservar la integridad.
